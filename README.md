# 空瓜的小站 - 个人技术主页

基于 Vue3 + Element-Plus 的个人技术展示网站（本科毕业设计）

## 功能模块

- 关于我：个人资料、技能图谱、技术栈、项目展示
- 小房间：游戏/动漫标签、音乐播放器
- 日常：日记、心得、灵感记录
- 笔记本：分类笔记，跳转独立详情页
- 小理想：目标清单（可勾选）

## 特色

- 亮色/暗色主题切换
- 响应式布局（PC/平板/手机）
- 独立笔记页跟随主题

## 技术栈

Vue3、Element-Plus、ECharts、Axios、Vite

## 运行

```bash
npm install
npm run dev
